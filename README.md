# qianjin-novel-writer

> 网文/小说写作专家技能 · 兼顾平台爆款节奏与文学文采

一个资深网文写作引擎技能（Skill），帮助用户从零创作符合平台调性、能引发强烈共鸣的爆款网络小说。覆盖选题脑洞、世界观设定、人物情绪设计、宏观大纲到章节精写的完整链路。

## 核心能力

- **平台爆款方法论**：番茄小说 / 起点中文 / 知乎盐选 / 通用短篇，各有不同的节奏、字数、钩子公式
- **宏大章节规划**：百章长篇骨架到 18 章短篇，伏笔/高潮/反转节奏精控
- **人物情绪冲突**：灵魂场景 + 反差设计 + 信念即心声，让人物从"符号"变"人"
- **智谋博弈与悬疑布局**：多势力权谋地图 + 4-6 层反转链条，信息差驱动
- **系统流金手指设计**：明确的等级升级路径 + 代价/真相/对立面（含可复用的「情绪系统」范式）
- **细腻情感叙述**：每章慢镜头白描，节制有力，给宏大叙事注入温度
- **科幻与脑洞架构**：严谨且富有想象力的世界观，荒诞与合理的最佳平衡
- **三大质量引擎（v2.0 新增）**：文笔质感引擎（AI 破绽扫描 + 展示而非告知）、剧情逻辑引擎（世界规则台账 + 读者三问压力测试）、代入感引擎（限知视角 + 感官锚定）；成稿「三审」不过不发
- **百万字长篇架构（v2.1 新增）**：主线/支线/暗线 Thread Tracker + 伏笔回收台账 + 人物圣经与声口差异化 + 六位著名作家方法对标（金庸/路遥/猫腻/马伯庸/GRRM/托尔金），长篇情节连贯、智商在线

## 设计信条

1. 爽与文采不矛盾（番茄炒蛋，一起做才好吃）
2. 每章留一个"慢镜头"
3. 设定之外要有人物困境
4. 反转从人物选择中长出，不靠设定硬推

## 使用方式

在 WorkBuddy / CodeBuddy 等支持 Skill 的智能体中，直接对话即可触发：

- "帮我写一篇番茄风格的小说"
- "给我几个科幻脑洞选题"
- "设计主角的金手指系统，要有升级路径和代价"
- "规划一部 18 章短篇大纲，每章带情绪爆点"
- "这情节逻辑经不起推敲，帮我合理化"

也可在对话中显式调用 `/qianjin-novel-writer`。

## 跨平台使用

本技能为纯 Markdown 知识包，可复制到任意支持 System Prompt / 角色设定的平台（OpenClaw、Claude、ChatGPT 等）使用。
