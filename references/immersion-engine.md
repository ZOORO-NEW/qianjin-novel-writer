# 读者代入感引擎 · immersion-engine

> 审核退回「读者代入感较弱」的根因：上帝全知视角乱跳、缺感官锚定、情绪跳变、作者旁白侵入、读者找不到自己。本文件给一套"把读者放进角色身体"的技法。

---

## 一、限知视角锁死（POV Lock）

- 每章（或每场景）**只锁一个角色的视角**，只写他"能感知到"的。
- 他不知道的 = 读者不知道（用"信息差"造悬念，不靠"上帝剧透"作弊）。
- 切视角必须空行 / 小节明确分隔，禁止同一段里 A 想完 B 想。
- **代入感命门**：读者是用"角色的眼睛"在看，不是听作者讲。

---

## 二、感官锚定开场（Sensory Anchoring）

每个场景开篇 1-2 句给**具体感官**，把读者一把放进现场：

- 坏：他走进房间，心情沉重。
- 好：门一开，一股霉味先撞过来。灯是坏的，只有窗缝漏进一线灰白的光。

五种感官任取：光 / 声 / 味 / 触 / 温度。优先"非视觉"（味、触、声）更抓人。

---

## 三、内心独白作桥（Internal Monologue Bridge）

用角色心声代替作者总结。独白要"带缺陷"——犹豫、自欺、误判，不要金句化：

- 坏（旁白）：他明白自己已经输了。
- 好（独白）："再来一次，我肯定能赢。"——他第几次这么说了？他自己也记不清。

---

## 四、让读者站在角色旁边（Stand Beside）

- **共情启动器**：开场先给一个读者能映射的微小困境 / 身体感受（赶时间、饿、手冷、被误解），再铺宏大设定。
- **one small true detail 规则**：每章至少一个"真人会做的小动作"（抠指甲、把硬币翻来翻去、对着电梯镜子整理头发），读者靠这种细节认出"这是个人"。
- 避免一上来抛设定名词海。先有人，再有世界。

---

## 五、情绪连续不跳变（Emotional Continuity）

- 情绪转变须有**台阶**：不能上一秒大笑下一秒殉情无理由。
- 用"过渡事件"连接：笑 → 听到一句刺心的话 → 笑容僵住 → 低头 → 沉默。一步步来。
- 角色情绪要和"他刚经历的事"匹配，作者不能为了催泪强行切换。

---

## 六、避免作者侵入（No Authorial Intrusion）

- 不跳出来讲大道理、不做"由此可见"式总结。
- 主题靠情节本身体现，不靠旁白点破。
- 读者要自己"悟"，悟到的比被告知的记得牢十倍。
- **禁创作/规划词汇侵入（最易被忽略的 AI 破绽）**：角色与旁白只能使用故事世界内部的语言。以下"作者层"词汇**一律禁止**写进正文或角色口中——大纲、第X卷、第X章、棋局/这盘棋、伏笔（作名词指"作者埋的伏笔"义）、设定（"这是设定"义）、爽点、反转（"剧情反转"义）、金手指、主线、暗线（"故事暗线"义）、钩子、铺垫、节奏（指"卷/章结构节奏"义）。
  - **为什么**：这类词是 AI 在生成时调用了自身"创作笔记/大纲文档"的残留，角色不可能知道"大纲""第几卷""棋局"，说出来就是第四面墙破裂，立刻暴露 AI 写作。
  - **正确写法**：用角色感官与具体事态承载。例：
    - ❌ "这是大纲里写好的设定。但面对事实，他感到巨大的荒谬感。"
    - ✅ "可真把它压在指尖下，他还是觉得荒唐。"
    - ❌ "第三卷的棋局，已经正式开始了。"
    - ✅ "真正的较量，已经正式开始了。"
  - **自检**：成稿后全文搜上述词，凡命中且不在"作者创作笔记/大纲文档"语境（如 SKILL 自身的设定说明）的，一律改为角色视角呈现。

---

## 七、代入感自检清单

- [ ] 本章锁死单一视角？无上帝视角乱跳？
- [ ] 场景开篇有感官锚定（非纯视觉优先）？
- [ ] 有内心独白作桥，且独白带缺陷不金句化？
- [ ] 开场先有读者可映射的微小困境 / 身体感受？
- [ ] 至少一个"真人小动作"细节？
- [ ] 情绪转变有台阶，不跳变？
- [ ] 无作者跳出来讲道理？
- [ ] 无创作/规划词汇侵入（大纲 / 第X卷 / 第X章 / 棋局 / 伏笔 / 设定 / 爽点 / 反转 / 金手指 / 主线 / 暗线 / 钩子 / 铺垫 未出现在正文或角色口中）？
