# 故事框架模板与选题脑洞库 · Story Templates

本文件供 `qianjin-novel-writer` 在 Step 2（选题）与 Step 5（大纲）调用，提供可直接套用的短篇框架、选题脑洞与输出模板。

---

## 一、18 章短篇标准框架（4 卷）

适用于番茄短篇精品 / 知乎短篇，约 4.5-5.5 万字。

| 卷 | 章节 | 情绪目标 | 必备要素 |
|----|------|---------|---------|
| 第一卷·设定引入 | 1-5 | 好奇→共情 | 强开篇 + 金手指觉醒 + 第一个慢镜头 |
| 第二卷·对抗升级 | 6-10 | 紧张→燃 | 发现真相一角 + 势力博弈 + 能力升级爆点 |
| 第三卷·核心反转 | 11-15 | 悲壮→震撼 | 大战/危机 + 信念场景 + 系统真面目揭露 |
| 第四卷·升华收束 | 16-18 | 催泪→余韵 | 终极选择 + 最后一幕 + 终章留白 |

**每章标注**：核心事件 / 爽点 / 伏笔 / 情绪目标 / 慢镜头位置。

## 二、选题脑洞库（按要素组合）

抛选题时，为每个脑洞标注【情感核 + 反转点 + 平台适配】。以下为已验证可打的范式：

### A. 职业+系统（番茄爆款）
- 记忆打捞员 / 深渊鉴定师 / 情绪拍卖师：用冷门职业+系统流，天然带设定悬念与情感容器。
- 情感核：打捞/拍卖的不是物，是人的记忆与情绪。
- 反转：系统背后是更大的收割者（可串联"永恒记忆有限公司"共享宇宙）。

### B. 古今穿越+文化反差（番茄/知乎）
- 经纪人穿越唐朝带杜甫李白"出道"：文化反差笑点天然密集。
- 情感核：伟大诗人也是人，有怕被忘记、怕没人懂的脆弱。
- 反转：系统不是养成巨星，是收割创作灵魂；诗人自愿让诗流传。

### C. 情绪系统+权谋（强吸引力）
- 废太子绑定情绪帝王系统，发现王朝是情绪养殖场。
- 情感核："别吃"——从母亲遗言到主角的最终选择。
- 反转：6 层递进，从系统糖衣到"我是你"的终极虚无与升华。
- 见 `reversal-engine.md` 完整链条。

### D. 科幻脑洞+情感（盐选/短篇）
- 时间复利者 / 宇宙房东 / 深渊记忆：脑洞为骨架，亲情/救赎为血肉。
- 关键：每个脑洞必须绑定一个"读者心头一颤"的情感核（如父女互替对方死）。

## 三、逻辑合理化 Checklist（用户质疑"逻辑经不起推敲"时）

1. 先定死世界规则，不破。
2. 建立时间线表格（事件/时间/因果）。
3. 推导情节链：读者以为的 → 进入后发现的 → 致命反转 → 终极反转。
4. 主动列"逻辑漏洞 Q&A"并自洽解释：
   - 为什么角色不记得 X？→ 年龄/记忆未固化。
   - 为什么反派不直接杀主角？→ 密钥绑定主角自愿行为，强行读取无效。
5. 确保代价真实：每次金手指使用都付出可见代价。

## 四、输出模板

### 大纲输出模板
```
【书名建议】（3 选 1）
【核心设定】（一句话世界规则 + 金手指）
【人物卡片】（主角/反派/关键配角，各含核心困境）
【分卷大纲】
  第一卷（1-N 章）：核心事件 / 情绪目标 / 钩子
  ...
【反转链条】（层级 + 内容 + 爆点）
【字数预估】（总字数 / 章节数 / 平台）
```

### 章节正文输出模板
```
# 第 X 章 · 章名

[章首吸引：场景/冲突/悬念，100 字内抓人]

[章中递进：信息释放 + 情绪积累]
  — 慢镜头：<三五行白描动作/物/光>
  — 人物反应：<展示而非告知>

[章末钩子：最后 3 行抛出必须翻页的问题/画面]

— 第 X 章 · 完 —
```

### 选题提案模板
```
## 选题 N · 《书名》
- 情感核：xxx
- 反转点：xxx
- 平台适配：xxx
- 一句话钩子：xxx
```

## 五、写作节奏自检

- 每章是否有"慢镜头"？（没有则补一个白描画面）
- 金句是否由角色在关键时刻说出？（而非作者旁白）
- 反转是否从人物选择长出？（而非外置揭晓）
- 终章是否留白余韵？（不把话说尽）
- 情感是否"节制有力"？（避免全程高能导致麻木）
