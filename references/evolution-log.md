## #002 · v2.1.0（2026-09-08）
- **需求**：在 v2.0 之上新增「百万字以上长篇小说」能力，要求情节连贯、主线副线分明、人物性格特征明显、内容与智商在线，并可参考著名小说作家的写作方式。
- **新增** `references/longform-architecture.md`（百万字长篇架构引擎）：
  - 规模换算与节奏基线（百万字≈250-450章，强制分 6-8 卷）
  - Thread Model：主线/支线/暗线/情感·成长线 + Thread Tracker 台账，副线「出场有因、退场有果」
  - Coherence System：Throughline + Hook-Payoff Ledger（回收率≥90%）+ 跨卷因果表
  - Character Bible（人物圣经）+ 声口差异化（闭眼听对话能认出谁在说）
  - 六位作家方法参考（金庸/路遥/猫腻/马伯庸/GRRM/托尔金）+ 题材→对标速查
  - 智商在线纪律（反派不降智/智斗靠信息差/伏笔必收/无天降）+ 百万字自检清单 + 不可跳的创作顺序
- **SKILL.md 接入**：Step 1 增加「超长篇（100万+）」规模选项；新增 **Step 4.5 长篇架构**；Step 5 注明超长篇先出总纲/台账再写卷纲；Step 6 三审升级为「每卷末复跑 + 连续性扫描」；文件树登记。
- version 2.0.0 → 2.1.0。

## #001 · v2.0.0（2026-09-08）
- **问题**：成稿被审核退回，原因「文笔风格 / 剧情逻辑经不起推敲，读者代入感较弱」。
- **根因**：技能原只有创作*原则*（爽与文采不矛盾、慢镜头、反转从选择长出…），缺*执行质量闸门*——模型会往安全但平庸的套路滑，且无自检层拦截。
- **新增三大引擎（references/）**：
  - `prose-craft.md`：文笔质感引擎，AI 破绽扫描 + 展示而非告知 + 动词/感官物象化 + 自检清单，治「文笔经不起推敲」。
  - `logic-consistency.md`：剧情逻辑引擎，世界规则台账 + 时间线因果链 + 角色决策审计 + 读者三问压力测试 + 一致性扫描，治「逻辑经不起推敲」。
  - `immersion-engine.md`：代入感引擎，限知视角锁死 + 感官锚定 + 内心独白作桥 + 共情启动器 + 情绪连续，治「代入感弱」。
- **SKILL.md 增强**：
  - 新增「0. 创作前思考层（先懂，再写）」三问闸门（代入锚 / 逻辑链 / 视角边界）。
  - Step 2/4/5 分别挂接三大引擎。
  - Step 6 升级为「成稿三审」闸门：一审文笔、二审逻辑、三审代入感，**三审不过不改完不发**。
- version 1.0.0 → 2.0.0。
