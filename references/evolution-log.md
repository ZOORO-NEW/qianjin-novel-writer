## #001 · v2.0.0（2026-09-08）
- **问题**：成稿被审核退回，原因「文笔风格 / 剧情逻辑经不起推敲，读者代入感较弱」。
- **根因**：技能原只有创作*原则*（爽与文采不矛盾、慢镜头、反转从选择长出…），缺*执行质量闸门*——模型会往安全但平庸的套路滑，且无自检层拦截。
- **新增三大引擎（references/）**：
  - `prose-craft.md`：文笔质感引擎，AI 破绽扫描 + 展示而非告知 + 动词/感官物象化 + 自检清单，治「文笔经不起推敲」。
  - `logic-consistency.md`：剧情逻辑引擎，世界规则台账 + 时间线因果链 + 角色决策审计 + 读者三问压力测试 + 一致性扫描，治「逻辑经不起推敲」。
  - `immersion-engine.md`：代入感引擎，限知视角锁死 + 感官锚定 + 内心独白作桥 + 共情启动器 + 情绪连续，治「代入感弱」。
- **SKILL.md 增强**：
  - 新增「0. 创作前思考层（先懂，再写）」三问闸门（代入锚 / 逻辑链 / 视角边界）。
  - Step 2/4/5 分别挂接三大引擎。
  - Step 6 升级为「成稿三审」闸门：一审文笔、二审逻辑、三审代入感，**三审不过不改完不发**。
- version 1.0.0 → 2.0.0。
