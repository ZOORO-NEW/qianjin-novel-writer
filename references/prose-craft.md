# 文笔质感引擎 · prose-craft

> 审核退回常写「文笔风格经不起推敲」。本质不是"不够华丽"，而是：抽象词堆砌、AI 套话、无信息量的修饰、情绪靠"告知"不靠"展示"。本文件给一套可执行的文笔纪律 + 正反样例，让每一句都"像真人写、经得起读第二遍"。

---

## 一、AI 文笔破绽扫描（成稿前必删清单）

模型天生会往这些安全但虚假的套路滑。每写完一章，逐条扫：

1. **抽象填充词**：「一种说不出的感觉」「莫名地」「某种说不清的」「些许」「难以名状」「一股……涌上心头」。→ 换成具体动作/物象。
2. **程式化前缀**：「随着……」「当……的时候」「在这个……的时代/世界里」「此刻」「瞬间」「不知为何」「不得不说」。→ 直接切到内容。
3. **弱化被动**：「不禁 / 不由得 / 下意识地 / 鬼使神差地」滥用（每章 ≤1 次，多了＝没写清为什么）。
4. **比喻俗套**：「仿佛……一般」「像……一样」连篇；宏大意象（灯塔 / 基石 / 洪流 / 巨轮 / 星辰大海）。→ 喻体要俗、要具体、要新。
5. **程度副词泛滥**：很 / 非常 / 十分 / 极其 / 格外。→ 删掉，用动词和名词扛信息。
6. **成语 / 四字词堆砌**：四个成语凑一句＝修辞噪音。每章成语 ≤2。
7. **感叹号通胀**：「太强了！！！」→ 平静叙述更有力。
8. **伪深刻金句**：放之四海皆准的"人生道理"句。→ 金句必须角色在特定情境用灵魂说出。

## 二、展示而非告知（show, don't tell）进阶

把"他很难过"翻译成一个动作 + 一件物。

| 告知（坏） | 展示（好） |
|---|---|
| 他感到一阵屈辱 | 他把手慢慢插进口袋，摸到了里面那个洞——破了一年的洞，缝过三次，又破了 |
| 她很紧张 | 她把杯子的把手转了半圈，又转回去，再转半圈。水晃出来，溅在手背上 |
| 气氛很压抑 | 没人说话。风扇的嗡嗡声忽然显得很大。窗外的蝉也停了 |
| 他爱她 | 他记得她不吃香菜。每次点外卖，备注栏都先写这句，再写别的 |

**原则**：读者要"感到"，不要"被告知"。情绪 = 身体反应 + 物件 + 环境，三者任取其二即成立。

## 三、动词精确化

一个准动词顶十个修饰词。

- 坏：他**非常生气地**把门**用力地关上**。
- 好：他摔上门。门框抖了三下。
- 坏：她**缓缓地、温柔地**摸了摸孩子的头。
- 好：她把手掌贴在孩子额头上，停了一秒，像在确认什么。

---

## 四、感官物象化（把情绪译成物）

抽象情绪 → 颜色 / 质地 / 气味 / 温度的具体物。

- 坏：他心中充满了说不清的悲伤。
- 好：那悲伤是潮的，像梅雨季的墙角，摸一下一手青灰。
- 坏：她觉得生活没有希望。
- 好：锅里的粥糊了底，她盯着那层黑，没去刮。

---

## 五、慢镜头白描（每章至少一个）

三五行白描动作 / 物 / 光，读者读完记住的就是这三五行。

> 杜甫把那张纸折了起来。折得很慢，很仔细。每一个折痕都压得平平的。最后折成一个很小很小的方块，塞进了怀里。

---

## 六、金句归位（角色说，不旁白）

金句不是作者总结，是人物在关键时刻用全部灵魂说的一句话。

- 坏（旁白）：这说明，真正的强大是温柔。
- 好（角色）："诗不是用来流传的。诗是用来，在黑夜里给另一个人点一盏灯的。"

---

## 七、文笔自检清单（成稿前过一遍）

- [ ] 删光了所有「一种说不出的 / 莫名地 / 随着 / 当……时」？
- [ ] 没有一句"他很难过 / 很紧张 / 很生气"式的告知，都换成展示？
- [ ] 程度副词（很 / 非常 / 十分）全删了？
- [ ] 每个比喻的喻体是具体的、俗的、读者能脑补的？没有灯塔 / 基石 / 洪流？
- [ ] 本章成语 ≤2？
- [ ] 至少一处慢镜头白描？
- [ ] 读 aloud 像人说话，不像语文课文？
